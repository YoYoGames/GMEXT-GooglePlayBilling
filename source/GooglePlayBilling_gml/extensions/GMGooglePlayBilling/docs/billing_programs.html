Billing Programs

This module provides functions for alternative/external billing programs, the Billing Choice program, and in-app messages.

Functions

The following functions are provided to work with billing programs and in-app messages:

  • play_billing_create_alternative_billing_only_reporting_details_async
  • play_billing_create_billing_program_reporting_details_async
  • play_billing_show_billing_program_information_dialog
  • play_billing_show_alternative_billing_only_information_dialog
  • play_billing_launch_external_link
  • play_billing_show_in_app_messages
  • play_billing_get_billing_choice_info_async

Structs

The following structs are used by the billing program functions:

  • GooglePlayBillingReportingDetails
  • GooglePlayBillingExternalLinkLaunchOptions
  • GooglePlayBillingInAppMessageOptions
  • GooglePlayBillingInAppMessageResult
  • GooglePlayBillingChoiceInfo

Constants

The following constants are used by the billing program functions:

  • GooglePlayBillingProgram
  • GooglePlayBillingInAppMessageResponseCode
  • GooglePlayBillingInAppMessageCategory

play_billing_create_alternative_billing_only_reporting_details_async

This function creates the reporting details required to report a transaction made through the alternative-billing-only program (see GooglePlayBillingFeatureType's AlternativeBillingOnly) back to Google, as required by Google Play policy.

Note

GooglePlayBillingInitOptions.enable_alternative_billing_only must have been enabled in play_billing_init.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_create_alternative_billing_only_reporting_details_async(callback)
Argument Type Description
callback Function The function to call once the request finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the request finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the request
reporting_details GooglePlayBillingReportingDetails The reporting details to report to Google; absent on failure


Example:

play_billing_create_alternative_billing_only_reporting_details_async(function(_billing_result, _reporting_details) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok && !is_undefined(_reporting_details)) {
        show_debug_message($"Report token: {_reporting_details.external_transaction_token}");
    }
});
This code creates the reporting details for an alternative-billing-only transaction.

play_billing_create_billing_program_reporting_details_async

This function creates the reporting details required to report a transaction made through the given billing program back to Google, as required by Google Play policy. This replaces the deprecated createExternalOfferReportingDetailsAsync API.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_create_billing_program_reporting_details_async(program, callback)
Argument Type Description
program GooglePlayBillingProgram The billing program the transaction was made through
callback Function The function to call once the request finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the request finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the request
reporting_details GooglePlayBillingReportingDetails The reporting details to report to Google; absent on failure


Example:

play_billing_create_billing_program_reporting_details_async(GooglePlayBillingProgram.ExternalOffer, function(_billing_result, _reporting_details) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok && !is_undefined(_reporting_details)) {
        show_debug_message($"Report token: {_reporting_details.external_transaction_token}");
    }
});
This code creates the reporting details for a transaction made through the external offer program.

play_billing_show_billing_program_information_dialog

This function launches the Play Store system UI to show the user informational details about the given billing program before they use it.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_show_billing_program_information_dialog(program, callback)
Argument Type Description
program GooglePlayBillingProgram The billing program to show information about
callback Function The function to call once the dialog is dismissed


Returns:

N/A


Triggers:

Callback

This callback fires once, when the dialog is dismissed.

Key Type Description
billing_result GooglePlayBillingResult The result of showing the dialog


Example:

play_billing_show_billing_program_information_dialog(GooglePlayBillingProgram.ExternalOffer, function(_billing_result) {
    show_debug_message($"Information dialog dismissed with code: {_billing_result.code}");
});
This code shows the informational dialog for the external offer program.

play_billing_launch_external_link

This function launches the external link associated with the given billing program (e.g. a link to a website where the user can complete a purchase outside the app), if one is configured for the app.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_launch_external_link(options, callback)
Argument Type Description
options GooglePlayBillingExternalLinkLaunchOptions The billing program whose external link should be launched
callback Function The function to call once the flow completes or is dismissed


Returns:

N/A


Triggers:

Callback

This callback fires once, when the flow completes or is dismissed.

Key Type Description
billing_result GooglePlayBillingResult The result of launching the external link


Example:

play_billing_launch_external_link({ billing_program: GooglePlayBillingProgram.ExternalContentLink }, function(_billing_result) {
    show_debug_message($"External link flow finished with code: {_billing_result.code}");
});
This code launches the external content link associated with the app.

play_billing_show_in_app_messages

This function shows any pending Play Store in-app messages to the user (e.g. a message about a declined subscription renewal payment). Call this regularly, such as when your game resumes.

This function returns the immediate result of requesting the messages; the outcome of the message flow itself (once the user has seen and dismissed any messages) is delivered separately through callback.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_show_in_app_messages(options=undefined, callback)
Argument Type Description
options GooglePlayBillingInAppMessageOptions The message categories to show; when omitted, all categories are shown
callback Function The function to call once the message flow finishes


Returns:

GooglePlayBillingResult


Triggers:

Callback

This callback fires once, when the in-app message flow finishes.

Key Type Description
in_app_message_result GooglePlayBillingInAppMessageResult The result of the message flow


Example:

var _result = play_billing_show_in_app_messages(undefined, function(_in_app_message_result) {
    if (_in_app_message_result.response_code == GooglePlayBillingInAppMessageResponseCode.SubscriptionStatusUpdated) {
        // Re-query purchases/entitlements here.
    }
});
This code shows any pending in-app messages and re-queries entitlements if the user's subscription status changed.

play_billing_get_billing_choice_info_async

This function requests information about the Billing Choice program for display to the user, such as loyalty program details, before they choose a billing option.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_get_billing_choice_info_async(callback)
Argument Type Description
callback Function The function to call once the request finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the request finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the request
choice_info GooglePlayBillingChoiceInfo The Billing Choice information; absent on failure


Example:

play_billing_get_billing_choice_info_async(function(_billing_result, _choice_info) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok && !is_undefined(_choice_info)) {
        show_debug_message($"Loyalty info: {_choice_info.loyalty_info}");
    }
});
This code requests Billing Choice information and shows any loyalty program details.

GooglePlayBillingProgram

This enumeration contains the billing programs supported by play_billing_init's GooglePlayBillingInitOptions.

These constants are referenced by the following functions:

  • play_billing_create_billing_program_reporting_details_async
  • play_billing_show_billing_program_information_dialog
  • play_billing_is_billing_program_available_async

These constants are referenced by the following structs:

  • GooglePlayBillingReportingDetails
  • GooglePlayBillingExternalLinkLaunchOptions
  • GooglePlayBillingProgramAvailabilityDetails


Member Description
Unspecified No billing program specified.
ExternalContentLink The external content link program, letting users be redirected outside the app to purchase content.
ExternalOffer The external offer program.
ExternalPayments The external payments program.
BillingChoice The Billing Choice program, letting the user pick between Google Play billing and an alternative billing system at purchase time.

GooglePlayBillingInAppMessageResponseCode

This enumeration contains the outcomes of play_billing_show_in_app_messages's message flow, delivered as GooglePlayBillingInAppMessageResult's response_code.

These constants are referenced by the following structs:

  • GooglePlayBillingInAppMessageResult


Member Description
NoActionNeeded The message flow finished without changing the user's entitlements; no action is needed.
SubscriptionStatusUpdated The user's subscription status changed as a result of the message flow; re-query purchases/entitlements.

GooglePlayBillingInAppMessageCategory

This enumeration contains the in-app message categories that can be requested with GooglePlayBillingInAppMessageOptions.

These constants are referenced by the following structs:

  • GooglePlayBillingInAppMessageOptions


Member Description

SubscriptionUpdate Messages about a subscription status change (e.g. a declined renewal payment).
