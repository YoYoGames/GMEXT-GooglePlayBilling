play_billing_query_product_details_async

This function queries the Play Store for the details of one or more products, caching the native ProductDetails for each product found so it can later be used by play_billing_launch_billing_flow.

Note

Successful results are merged into the existing cache rather than replacing it, so you can query in-app products and subscriptions separately (or in multiple batches) without losing earlier results.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_query_product_details_async(products, callback)
Argument Type Description
products Array of GooglePlayBillingProductInput The products to query
callback Function The function to call once the query finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the query finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the query
query_result GooglePlayBillingProductDetailsQueryResult The products that were found and any that could not be fetched; always present, with empty arrays on failure


Example:

var _products = [
    { product_id: "single_time_purchase", product_type: GooglePlayBillingProductType.InApp },
    { product_id: "premium_subscription", product_type: GooglePlayBillingProductType.Subscription }
];

play_billing_query_product_details_async(_products, function(_billing_result, _query_result) {
    if (_billing_result.code != GooglePlayBillingResponseCode.Ok) exit;

    for (var i = 0; i < array_length(_query_result.products); i++) {
        var _product = _query_result.products[i];
        show_debug_message($"{_product.title}: {_product.product_id}");
    }
});
This code queries a one-time product and a subscription, then logs the title of every product found.

play_billing_clear_products

This function clears the native ProductDetails cache populated by play_billing_query_product_details_async. Products must be queried again before they can be used with play_billing_launch_billing_flow.


Syntax:

play_billing_clear_products()


Returns:

N/A


Example:

play_billing_clear_products();
This code clears the cached product details.

play_billing_launch_billing_flow

This function launches the Play Store purchase UI for one or more products previously cached by play_billing_query_product_details_async. It supports a single purchase, a bundle of multiple one-time products, or a subscription with add-ons, and can replace (upgrade/downgrade) an existing subscription in the same flow.

This function only returns the immediate result of launching the flow. The actual purchase result (success, cancellation, etc.) is delivered later through the callback registered in play_billing_init, exactly like any other purchase update.

Note

Each product in items must already be present in the cache populated by play_billing_query_product_details_async; otherwise this function fails with GooglePlayBillingResponseCode.DeveloperError before reaching Google.


Syntax:

play_billing_launch_billing_flow(items, options=undefined)
Argument Type Description
items Array of GooglePlayBillingProductDetailsParams The products to purchase in this flow
options GooglePlayBillingFlowOptions Options controlling the billing flow


Returns:

GooglePlayBillingResult


Example:

var _items = [
    { product_id: "single_time_purchase" }
];

var _result = play_billing_launch_billing_flow(_items);
if (_result.code != GooglePlayBillingResponseCode.Ok) {
    show_debug_message($"Failed to launch billing flow: {_result.code}");
}
// The purchase outcome itself arrives later through play_billing_init's callback.
This code launches the purchase flow for a single one-time product.

GooglePlayBillingSubscriptionReplacementMode

This enumeration contains the ways an existing subscription can be replaced by GooglePlayBillingSubscriptionUpdateParams.

These constants are referenced by the following structs:

  • GooglePlayBillingSubscriptionUpdateParams


Member Description
UnknownReplacementMode No replacement mode specified; the billing flow fails if a replacement is required.
WithTimeProration The new plan takes effect immediately; remaining time from the old plan is credited towards the new plan's billing period.
ChargeProratedPrice The new plan takes effect immediately and the user is charged the prorated price difference immediately.
WithoutProration The new plan takes effect immediately without any proration.
ChargeFullPrice The new plan takes effect immediately and the user is charged the new plan's full price immediately, without proration.
Deferred The new plan takes effect when the old plan's current billing period expires.
KeepExisting The existing plan is kept as-is; no replacement occurs.

GooglePlayBillingFlowOptions

This struct configures options for play_billing_launch_billing_flow. Every member is optional; Google applies only the options actually present.

This struct is referenced by the following functions:

Member Type Description

obfuscated_profile_id String An obfuscated identifier for the user's in-game profile, echoed back on the resulting GooglePlayBillingPurchase; must not contain PII and must not exceed 64 characters
