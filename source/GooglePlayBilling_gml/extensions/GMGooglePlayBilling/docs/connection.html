Connection

This module provides functions for initializing the extension, connecting to the Play Store, and checking availability of billing config/features/programs before using the rest of the API.

Functions

The following functions are provided to initialize and connect to the Play Store:

  • play_billing_init
  • play_billing_start_connection
  • play_billing_end_connection
  • play_billing_get_connection_state
  • play_billing_is_ready
  • play_billing_get_config_async
  • play_billing_is_alternative_billing_only_available_async
  • play_billing_is_billing_program_available_async
  • play_billing_is_feature_supported

Structs

The following structs are used by the connection functions:

  • GooglePlayBillingInitOptions
  • GooglePlayBillingResult
  • GooglePlayBillingConfig
  • GooglePlayBillingProgramAvailabilityDetails

  • GooglePlayBillingConnectionState

  • GooglePlayBillingChoiceScreenType

play_billing_init

This function initializes the extension, creating the native BillingClient and registering the purchases-updated listener. It must be called before any other play_billing_* function.

The callback supplied here is stored and reused for the lifetime of the client: every time a purchase updates (a new purchase, a subscription renewal/upgrade, etc.) - including purchases started by play_billing_launch_billing_flow - Google delivers the result through this same callback.

Note

callback fires repeatedly for as long as the client exists, not just once after play_billing_init returns. If the current Android activity is unavailable when play_billing_init is called, callback fires immediately with only the billing_result argument (no purchases argument).

Calling this function again tears down and replaces any existing BillingClient (and its cached product details), so it should only be called once per app session, typically at startup.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_init(options=undefined, callback)
Argument Type Description
options GooglePlayBillingInitOptions Options controlling which optional billing capabilities are enabled
callback Function The function to call whenever purchases update


Returns:

N/A


Triggers:

Callback

This callback fires once for every purchases-updated event, for the lifetime of the client.

Key Type Description
billing_result GooglePlayBillingResult The result of the purchases-updated event
purchases Array of GooglePlayBillingPurchase The purchases that were updated; always a real (possibly empty) array


Example:

var _options = {
    enable_auto_service_reconnection: true
};

play_billing_init(_options, function(_billing_result, _purchases) {
    if (_billing_result.code != GooglePlayBillingResponseCode.Ok) exit;

    for (var i = 0; i < array_length(_purchases); i++) {
        var _purchase = _purchases[i];
        show_debug_message($"Purchase updated: {_purchase.purchase_token}");
    }
});

play_billing_start_connection(function(_billing_result) {
    show_debug_message($"Connected with code: {_billing_result.code}");
}, function() {
    show_debug_message("Billing service disconnected.");
});
This code initializes the extension and connects to the Play Store, listening for purchase updates.

play_billing_start_connection

This function establishes the connection between the BillingClient created by play_billing_init and the Google Play Store. It must succeed (billing_result.code equal to GooglePlayBillingResponseCode.Ok) before calling any other play_billing_* function that requires a ready client.

A successful connection does not guarantee the Play Store remains reachable - if the connection drops later, callback_disconnect fires and the client must call this function again to reconnect.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_start_connection(callback_start, callback_disconnect)
Argument Type Description
callback_start Function The function to call once the connection attempt finishes
callback_disconnect Function The function to call if the billing service disconnects after a successful connection


Returns:

N/A


Triggers:

Callback — start

This callback fires once, when the initial connection attempt finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the connection attempt


Callback — disconnect

This callback fires with no arguments whenever the billing service disconnects after having connected successfully. Call play_billing_start_connection again to reconnect.


Example:

play_billing_start_connection(function(_billing_result) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok) {
        show_debug_message("Connected to the Play Store.");
    }
}, function() {
    show_debug_message("Disconnected - will retry.");
    play_billing_start_connection(callback_start, callback_disconnect);
});
This code connects to the Play Store and reconnects automatically if the service disconnects.

play_billing_end_connection

This function closes the connection to the Play Store and releases the native BillingClient created by play_billing_init, clearing any cached product details.

Note

Call this function when your game shuts down, or before calling play_billing_init again to start a fresh session.


Syntax:

play_billing_end_connection()


Returns:

N/A


Example:

play_billing_end_connection();
This code closes the connection to the Play Store.

play_billing_is_ready

This function returns whether the BillingClient is ready to accept further requests (equivalent to play_billing_get_connection_state() == GooglePlayBillingConnectionState.Connected, but cheaper to check).


Syntax:

play_billing_is_ready()


Returns:

Boolean


Example:

if (!play_billing_is_ready()) exit;
play_billing_query_purchases_async(GooglePlayBillingProductType.InApp, false, callback);
This code exits early if the client is not ready before querying purchases.

play_billing_get_config_async

This function requests Play billing configuration data - currently the user's Play Store country as an ISO 3166-1 alpha-2 code, useful for showing localized pricing before a product query completes.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_get_config_async(callback)
Argument Type Description
callback Function The function to call once the request finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the request finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the request
config GooglePlayBillingConfig The billing config; absent if Google didn't deliver one, including on failure


Example:

play_billing_get_config_async(function(_billing_result, _config) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok && !is_undefined(_config)) {
        show_debug_message($"Store country: {_config.country_code}");
    }
});
This code requests the billing config and shows the user's store country.

play_billing_is_alternative_billing_only_available_async

This function checks whether the alternative-billing-only program (letting the user pay through a developer-managed payment system with no Google Play billing option at all) is available for the current user and app.

Note

The GooglePlayBillingInitOptions.enable_alternative_billing_only option must have been enabled in play_billing_init for this program to be usable.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_is_alternative_billing_only_available_async(callback)
Argument Type Description
callback Function The function to call once the check finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the availability check finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the availability check


Example:

play_billing_is_alternative_billing_only_available_async(function(_billing_result) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok) {
        show_debug_message("Alternative billing only is available.");
    }
});
This code checks whether the alternative-billing-only program is available.

play_billing_is_billing_program_available_async

This function checks whether the given billing program (see GooglePlayBillingProgram) is available for the current user and app.

Note

The corresponding GooglePlayBillingInitOptions.enable_* option must have been enabled in play_billing_init for the program to be usable.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_is_billing_program_available_async(program, callback)
Argument Type Description
program GooglePlayBillingProgram The billing program to check
callback Function The function to call once the check finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the availability check finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the availability check
availability_details GooglePlayBillingProgramAvailabilityDetails Details about the program's availability; absent only when the request never reached Google (e.g. the client is not ready)


Example:

play_billing_is_billing_program_available_async(GooglePlayBillingProgram.BillingChoice, function(_billing_result, _availability_details) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok && !is_undefined(_availability_details)) {
        show_debug_message($"Billing Choice available: {_availability_details.billing_program}");
    }
});
This code checks whether the Billing Choice program is available.

}
This code checks whether in-app messaging is supported on the current device.

GooglePlayBillingResponseCode

This enumeration contains the response codes returned by the Play Billing Library, delivered as GooglePlayBillingResult's code member.

These constants are referenced by the following structs:

  • GooglePlayBillingResult


Member Description
ServiceTimeout The request reached the maximum timeout before Google Play responded. Deprecated by Google; modern clients receive ServiceUnavailable instead.
FeatureNotSupported The requested feature is not supported by the Play Store on the current device.
ServiceDisconnected The app is not currently connected to the Play Store service.
Ok Success.
UserCanceled The user pressed back or canceled a dialog.
ServiceUnavailable The network connection is down.
BillingUnavailable This billing API version is not supported for the type requested.
ItemUnavailable The requested product is not available for purchase.
DeveloperError Invalid arguments were provided to the API, or the app is not correctly configured for billing in the Play Console.
Error A fatal error occurred during the API action.
ItemAlreadyOwned The purchase failed because the item is already owned.
ItemNotOwned The consume/acknowledge failed because the item is not owned.
NetworkError A network error occurred during the operation.

GooglePlayBillingInitOptions

This struct configures optional capabilities enabled when creating the BillingClient in play_billing_init. Every member defaults to false when omitted, including when the whole struct itself is omitted.

This struct is referenced by the following functions:

  • play_billing_init


Member Type Description
enable_auto_service_reconnection Boolean Whether the client automatically attempts to reconnect after an unexpected disconnection
enable_prepaid_plans Boolean Whether pending transactions are enabled for prepaid subscription plans
enable_alternative_billing_only Boolean Whether the alternative-billing-only program is enabled (see play_billing_is_alternative_billing_only_available_async)
enable_external_content_link Boolean Whether the external content link billing program is enabled (see GooglePlayBillingProgram)
enable_external_offer Boolean Whether the external offer billing program is enabled
enable_external_payments Boolean Whether the external payments billing program is enabled
enable_billing_choice Boolean Whether the Billing Choice program is enabled
