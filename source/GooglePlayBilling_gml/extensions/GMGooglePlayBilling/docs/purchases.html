Purchases

This module provides functions for querying, acknowledging and consuming the user's purchases.

Functions

The following functions are provided to work with purchases:

  • play_billing_query_purchases_async
  • play_billing_acknowledge_purchase
  • play_billing_consume_async

Structs

The following structs are used by the purchase functions:

  • GooglePlayBillingPurchase
  • GooglePlayBillingAccountIdentifiers
  • GooglePlayBillingPendingPurchaseUpdate

Constants

The following constants are used by the purchase functions:

  • GooglePlayBillingPurchaseState

play_billing_query_purchases_async

This function queries the user's current purchases of the given product type. Use this at startup to restore entitlements without requiring a fresh purchase, and to catch any purchase that still needs to be acknowledged or consumed.

Note

Query in-app products and subscriptions separately - do not call this function again for a different product_type while a previous call is still in flight, as this may cause the Play Store API to error.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_query_purchases_async(product_type, include_suspended_subscriptions, callback)
Argument Type Description
product_type GooglePlayBillingProductType The product type to query purchases for
include_suspended_subscriptions Boolean Whether suspended subscriptions should be included in the result
callback Function The function to call once the query finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the query finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the query
purchases Array of GooglePlayBillingPurchase The user's current purchases of the requested type; always a real (possibly empty) array


Example:

play_billing_query_purchases_async(GooglePlayBillingProductType.InApp, false, function(_billing_result, _purchases) {
    if (_billing_result.code != GooglePlayBillingResponseCode.Ok) exit;

    for (var i = 0; i < array_length(_purchases); i++) {
        var _purchase = _purchases[i];
        if (_purchase.purchase_state == GooglePlayBillingPurchaseState.Purchased && !_purchase.is_acknowledged) {
            play_billing_acknowledge_purchase(_purchase.purchase_token, callback);
        }
    }
});
This code queries the user's one-time purchases and acknowledges any that haven't been acknowledged yet.

play_billing_acknowledge_purchase

This function acknowledges a purchase or subscription. Every purchase - consumable or not - must be acknowledged within 3 days of being made, or it is automatically refunded by Google. Consumable purchases are acknowledged automatically by play_billing_consume_async; use this function for non-consumable one-time products and for subscriptions.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_acknowledge_purchase(purchase_token, callback)
Argument Type Description
purchase_token String The purchase token of the purchase to acknowledge
callback Function The function to call once the acknowledgement finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the acknowledgement finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the acknowledgement


Example:

play_billing_acknowledge_purchase(_purchase.purchase_token, function(_billing_result) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok) {
        // Grant entitlement to the non-consumable product/subscription here.
    }
});
This code acknowledges a purchase after it has been verified.

play_billing_consume_async

This function consumes a purchase, allowing the same product to be purchased again. Use this only for consumable one-time products (e.g. in-game currency); non-consumable products and subscriptions must instead be acknowledged with play_billing_acknowledge_purchase. Consuming a purchase acknowledges it at the same time - a separate acknowledge call is not needed.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

play_billing_consume_async(purchase_token, callback)
Argument Type Description
purchase_token String The purchase token of the purchase to consume
callback Function The function to call once the consumption finishes


Returns:

N/A


Triggers:

Callback

This callback fires once, when the consumption finishes.

Key Type Description
billing_result GooglePlayBillingResult The result of the consumption
purchase_token String The same purchase token that was passed in, echoed back


Example:

play_billing_consume_async(_purchase.purchase_token, function(_billing_result, _purchase_token) {
    if (_billing_result.code == GooglePlayBillingResponseCode.Ok) {
        // Grant the consumable (e.g. in-game currency) here.
    }
});
This code consumes a purchase after it has been verified, granting a consumable reward.

GooglePlayBillingPurchaseState

This enumeration contains the possible states of a GooglePlayBillingPurchase.

These constants are referenced by the following structs:

  • GooglePlayBillingPurchase


Member Description
UnspecifiedState The purchase state could not be determined.
Purchased The purchase has completed.
Pending The purchase is pending and has not completed yet (e.g. awaiting a pending cash transaction).

GooglePlayBillingPurchase

This struct describes a single purchase, delivered both by the purchases-updated callback registered in play_billing_init and by play_billing_query_purchases_async.

This struct is referenced by the following functions:

  • play_billing_init
  • play_billing_query_purchases_async


Member Type Description
order_id String The Google-assigned order ID; absent for some free/trial transactions
package_name String The app package name this purchase was made for
purchase_time Real The time the purchase was made, as milliseconds since epoch
purchase_token String The unique token identifying this purchase - pass this to play_billing_acknowledge_purchase, play_billing_consume_async, or as old_purchase_token on a subscription replacement
products Array of String The product IDs included in this purchase (more than one for a multi-product bundle)
signature String The signature used to verify this purchase, e.g. with your own backend
is_acknowledged Boolean Whether this purchase has already been acknowledged
is_auto_renewing Boolean Whether this purchase is a subscription that will auto-renew
purchase_state GooglePlayBillingPurchaseState The purchase's current state
quantity Real The quantity of the product purchased
original_json String The original JSON string returned by Google for this purchase, as needed for server-side signature verification
is_suspended Boolean Whether this purchase (subscription) is currently suspended
account_identifiers GooglePlayBillingAccountIdentifiers The obfuscated account/profile identifiers supplied when the purchase was made, if any
pending_purchase_update GooglePlayBillingPendingPurchaseUpdate Present only when this purchase has a pending update that hasn't completed yet
